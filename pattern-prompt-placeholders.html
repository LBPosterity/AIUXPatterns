Prompt Placeholder Values

Overview

Providing prompt placeholders for key values. Similar to prompt templates, this provides simplified inputs for key values inside a much larger & more complex prompt.

User Archetype

This pattern suits a two user workflow where user (A) composes a complex prompt & parametrises key values that affect the output. User (B) Then has a simpler experience filling out these key values only yet submits the full prompt.

Considerations

The overall prompt structure needs to be composed to ensure these variablised inputs can be switched out while keeping the prompt integrity. Also, the individual placeholders can be understood on their own for user (B).
